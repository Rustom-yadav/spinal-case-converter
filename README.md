# 🔗 Spinal Case Converter (JavaScript Only)

A logic-focused **Spinal Case Converter** implemented purely in **JavaScript**, designed to transform strings into standardized spinal-case format:


This project intentionally removes UI layers to highlight **core algorithmic thinking, regex mastery, and string normalization**.

---

## 🎯 Objective

The objective of this project is to:
- Convert various string formats into spinal case
- Handle casing, spacing, underscores, and camelCase
- Practice regex-based string transformation
- Demonstrate clean, reusable JavaScript logic

Logic first. Presentation optional.

---

## ✨ Key Features

- Converts:
  - camelCase
  - snake_case
  - space-separated strings
  - mixed-format inputs
- Outputs consistent spinal-case strings
- Case-insensitive processing
- Pure JavaScript implementation
- Reusable utility-style function

---

## 🧱 Tech Stack

- JavaScript (Vanilla)

No DOM. No styling. No dependencies.
